# 哥飞 SEO 实战口径

本文件是本 skill 的**实战判断口径**。来源是哥飞对谷歌排名因素的实战理解。与 [`zyppy-2026-ranking-factors.md`](zyppy-2026-ranking-factors.md) 的因素排序一致（F1–F10），但检查方法和处方以本文件为准。

**冲突时以本文件为准。** Zyppy 只用来校准「这十项仍是主表」和「没有线上数据就 Unknown」。本文件未写的 Zyppy 观察（如 Navboost、CWV 高估）可保留，但不能推翻下面的实战规则。

代码审计仍不能编造 GSC、外链表、品牌词量或行为数据。

## 十大因素（实战读法）

1. **内容相关性**：网页内容与用户搜索是否相关。用 TDH 是否含词、整页是否聚焦（密度能看出发散）来判断。
2. **反向链接**：没死，仍然很有用。有真实流量的来源页效果更好。2026 年比重已升到第二。
3. **内容质量**：原创性、准确性、时效性。
4. **权威性和信任度**：公司、品牌、创建者等多维评估。
5. **行为数据**：可以提升权重，以小博大、以弱胜强。
6. **品牌信号**：有唯一品牌名，真有人搜这个名字，并散布在互联网各处，能被识别为实体。
7. **用户满意度**：可并入第 5 点，但拆开也成立——好的行为数据不一定是最佳体验。禁止假排队。
8. **技术 SEO 健康度**：是否后端渲染，On Page 细节是否做完。
9. **主题权威性 / 主题聚焦度**：全站打一个大主题，比什么词都做更容易拿排名。对应两大原则：「一个关键词组一个页面」「举全站之力来打一个词」。
10. **内部链接**：分配权重，方便爬虫，帮助理解页面结构。

## F1 内容相关性

判断方法：看 **TDH（title / description / H1）是否包含关键词**，再看整页是否聚焦。内容发散时，关键词密度会偏低或被冲淡；要改到聚焦为止。

密度是**聚焦诊断**，不是公式。不存在官方最佳百分比，也不用 `3%–5%` 当达标线；但「密度太低 / 词只在角落出现」应报不聚焦，不是忽略。堆砌仍然要报。

要做好相关性，逐项检查：

1. 搜索意图匹配。
2. 页面内容与关键词语义相关。
3. 整个网站的主题跟当前页面主题一致。
4. 页面标题与关键词相关。
5. Headings 与关键词相关。
6. 网页语言与用户搜索语言一致。
7. 用户所在地区与网页描述的地理相关。
8. H1 与关键词相关。
9. 副标题与关键词相关。
10. URL 与关键词相关。
11. 域名与关键词相关。
12. Meta 与关键词相关。

对应代码规则：`KEYWORD_TDH_GAP`、`KEYWORD_HEADING_GAP`、`KEYWORD_URL_GAP`、`KEYWORD_META_GAP`、`KEYWORD_LANGUAGE_GAP`、`KEYWORD_UNFOCUSED`、`KEYWORD_STUFFING`、`KEYWORD_NOT_FOUND`。地理相关性无目标市场时保持 `Unknown`。

### 关键词域名

提倡用关键词注册域名，因为有用，但是加分有限：不是注册了就一定行。已有品牌域不是关键词域 **不** Fail，也不必为了 SEO 改名。不要买连字符堆词的垃圾 EMD。

## F2 反向链接

不是有了外链就一定行，也不是缺了就一定不行。多数有竞争的词，没有外链万万不行。

| 场景 | 口径 |
|---|---|
| 新词 + 新站 | 可以不用外链就拿到排名（近年多次验证） |
| 老词 + 新站 | 必须有外链，没外链不会有结果；有了也还要 On Page 和行为数据 |
| 有竞争的词 | 通常必须有外链 |

互联网靠链接连接，这是天然的权重和信任传递。无链接表时因素状态仍是 `Unknown`，但报告必须写出上面的场景口径，不要写「外链没用了」。

好外链特征（有表才评；无表逐项 Unknown）：

1. 来自高度可信域名：维基、政府、大学、知名公益机构等。
2. 来自主题相关页面。不相关不是没用，只是没那么有用。高相关一般很贵，预算有限可买大方向相关。
3. 域名 / 网站级权威。
4. 页面级权威。高权站上的自定义目录若是孤岛（站内没有别的页链过来），看起来权高也没用。Adsy 一类「注册后在自己目录下发」的链接按此过滤。
5. 来自有真实流量的页面，最好有自然搜索流量。
6. 来自本身有很多引荐域名的页面。只靠内链的页传不出多少权。
7. 锚文本不能太单一，否则像非自然外链，有惩罚风险。
8. 来自本身有很多外链的页面（引荐页面数，区别于第 6 点的引荐域名数）。
9. 锚文本就是目标关键词最好；同时围绕核心词做多种表达，分散到多条链接里制造多样性。精确匹配是优选，不是要避免的毒药。
10. Nofollow 仍有正面效果，尽管不大，可以要。
11. 低质量、PBN、已被证明是买卖的外链，有负面影响。

## F5 / F7 行为与满意度

行为数据可以以小博大。满意度可以并进行为，但两者不是同一件事：生成特别快、对手稍慢时，谷歌可能觉得对手行为数据更好，用户却对你更满意。

禁止假排队、伪造停留、点击或转化来造行为数据。

无 GSC / 用户研究时，线上行为与真实满意度保持 `Unknown`。代码侧仍查 CTR 文案和任务能否完成。

## F8 技术健康度

页面内容应后端渲染（初始 HTML 有正文）。On Page 细节（TDH、canonical、内链、图片、语言）按 F1/F10 和本文件检查，技术阻断仍按 rubric 的 P0/P1。

## F9 主题聚焦

- **一个关键词组一个页面**：一个 URL 打一个词组，不要一页抢多组完全不同的词。
- **举全站之力来打一个词**：导航、内链、相关页、集群都指向要打的主词/主词组，而不是每个词各玩各的。

全站主题与当前页主题不一致，记 F1 第 3 项和 F9。

## F10 内部链接

合理内链分配权重，让爬虫更容易爬、更容易理解结构。输出必须是来源页 / 锚文本 / 目标页 / 原因。这是「举全站之力」的执行面。
